  Its stable public npm tarballs were already cached; their SHA-512 digests match

CommonJS API:
  const { openIsolatedLesson } = require('.\\testing\\browser\\isolated.cjs');
  async function checkLesson(relativeRepoPath) {
    const session = await openIsolatedLesson(relativeRepoPath);
    try {
      console.log(session.browserVersion, await session.page.title());
    } finally {
      await session.close();
    }
  }
  checkLesson('testing\\browser\\fixtures\\counter.html').catch(console.error);

Runnable fixture example, from the repository root:
  node -e "require('.\\testing\\browser').openIsolatedLesson('testing\\browser\\fixtures\\counter.html').then(async s => {try {console.log(s.browserVersion, await s.page.title())} finally {await s.close()}}).catch(e => {console.error(e);process.exitCode=1})"

Each call launches its own fresh HEADLESS Edge browser, context, and page. Multiple
calls can run concurrently; there is no integrated-browser connection, focus
request, shared profile, or shared context. Always await close() in finally.
Repeated or concurrent close() calls reuse the same cleanup promise. Context
cleanup errors still trigger browser shutdown. Load/setup failures clean up
before rejecting; simultaneous load and cleanup errors retain both causes.
Each spawned Edge process also gets a unique owned TEMP/TMP/TMPDIR directory.
The helper removes that directory, including Edge's debug log, after browser
shutdown, even when navigation or context cleanup fails.

Only repository-relative existing files below learning\, capability\, or
testing\browser\fixtures\ are accepted. URLs, absolute paths, alternate data
streams, out-of-root traversal, directories, missing files, and junction escapes
are rejected with ERR_LESSON_PATH before launch. This validates the entry file;
it is not a network sandbox for arbitrary lesson scripts.

Require this helper before importing Playwright. It sets PLAYWRIGHT_BROWSERS_PATH
to repository\.git\kanban-orchestrator\browser-binaries before loading Playwright.
The installed msedge channel does not consume that download cache. It also sets
TEMP, TMP, and TMPDIR for the calling Node process to the repository-private
.git\kanban-orchestrator\browser-runtime so owned disposable profiles/artifacts
stay local; Playwright removes them when the owned browser closes. Parent shell
variables, existing user profiles, and global browser caches remain unchanged.

Evidence is in evidence\: tooling preflight, actual stub behavioral red, real
headless green, cached package/browser provenance, and cleanup. The earlier TLS
failure logs are tooling limits, not behavioral red. Red preceded implementation;
one additional no-fallback regression was added after the initial green.
A second focused behavioral red demonstrated missing per-session scratch

EXPLICIT CALLER-OWNED LOOPBACK EXTENSION

The original openIsolatedLesson(path) API and its eight tests remain file-only.
There is a separate API for an already-approved, caller-owned synthetic listener:

  const { openIsolatedLoopback } = require('.\\testing\\browser\\isolated.cjs');
  async function checkHost(startHost) {
    const fixture = await startHost(); // owned fixture returns { server, url, close }
    let session;
    try {
      session = await openIsolatedLoopback('capability\\C041\\index.html', fixture.server);
      // Use session.page for the real HTTP fixture's acceptance checks.
    } finally {
      try { if (session) await session.close(); } finally { await fixture.close(); }
    }
  }

The second argument MUST be the actual, already-listening Node http.Server,
not a URL, wrapper, arbitrary object, HTTPS server, or unstarted/closed server.
Its bound address must be IPv4 127.0.0.1 and its actual port an integer 1..65535.
The helper derives the literal HTTP origin from server.address(); no DNS,
credentials, remote origins, TLS changes, listener startup, or dependency install.
Invalid handles fail with ERR_LOOPBACK_SERVER before any browser launch.

The first argument still passes all existing local path/realpath guards. It is
an ownership anchor, NOT an arbitrary HTTP route: navigation is fixed to the
derived origin's "/". The caller must serve that owned entry at "/" and retain
its own consent, exact asset allowlist, hashes, Host/Origin checks, read-only
behavior, bounded listener lifetime (maximum 15 minutes), and server cleanup.
The helper does not prove that a listener body matches the anchor file.

Loopback contexts permit only GET/HEAD to that exact owned origin while the
server remains live at the same address/port. Other origins/ports, writes,
WebSockets, and service workers are blocked for navigations and subrequests.
All HTTP 3xx responses, including same-origin redirects, are deliberately denied.
Playwright does not re-run route.continue() guards on redirect hops, so this API
uses route.fetch({maxRedirects:0}) and fulfills non-3xx real server responses
unchanged. This is guarded HTTP forwarding via Playwright, not mocked response
content or evidence certifying Chromium's native TCP transport. The actual
browser still enforces the returned CSP, CORS, and opaque-origin sandbox rules.
Child response bytes and CSP preservation are checked in the real browser tests.
There is no general-purpose proxy/server and no OS-level network sandbox claim.

Browser/context/page isolation, sandboxing, private runtime and error cleanup
match the file-only API. close() NEVER closes the caller's listener; the caller
must close it in finally, including when opening the browser fails. For C020,
which returns the actual server directly, pass that server as the second argument.
