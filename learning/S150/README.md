that no remaining routing, sessions, jobs, artifacts or ownership leases depend

**No required dependency remains on v1; failed checks block retirement;
cleanup outcome and remaining resources are exportable.** Its original source

**no-v1-dependency verifier**. Every required dependency must be resolved,

readiness, original journey continuation and exactly-one-effect proof.

dominate uncertainty without hiding it. Desired 100% v2 routing, healthy v2
and 200 green requests cannot substitute for this proof.

Four rehearsals, five retirement checks per rehearsal, twelve trace events and
two fictional retention ticks are enforced. Bounds reject without evicting
history; one trace event is reserved for archive. All attempted checks and
original journeys remain counted until explicit reset. Requests are not
independent reliability trials.

stale/replayed, malformed and out-of-order commands reject without state changes.

is not zero. Missing observation is never coerced into absence of dependency.

they cannot erase a duplicate effect or an earlier interruption.

and mark relevant invalid inputs. Details retain current and archived evidence.

defaults and focuses the fixture. No control shadows native `form.reset()`.
The UI is responsive, with visible keyboard focus and labelled controls.
Run/revision tokens remain monotonic anti-replay bookkeeping across reset;
they are not native session or deployment progress.

CSP permits only external local scripts/styles and denies inline script/style,
network connections, frames, objects, workers, base changes and form navigation.
