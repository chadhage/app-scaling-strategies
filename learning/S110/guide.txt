Training rehearsal - synthetic data - not a live Azure result

Open index.html with model.js, lesson.js and lesson.css alongside it. No server,
installation, account or subscription is needed. All values are authored fictional

CONDUCT
1. Select a trace. Rehearse nominal 100% to origin-v2, epoch 2.
2. Before sampling, all evidence gates remain UNKNOWN. Check safe retirement now:
   it is UNVERIFIED, old origin retained. This mistake stays in history.
3. Sample three fictional POP/cohort observations and old work. Desired and
   effective epochs/origins are shown separately. Counts retain successful,
   interrupted, unknown and pending outcomes; a 200 response exceeding 120 ms
   is an interruption under this authored budget.
4. Check safe retirement. Only required observed routing + zero old work +
   successful in-budget journeys permit fictional retirement.
5. Conduct another trace without erasing prior attempts. Six runs / 24 events
   bound the exercise. Reset lesson and history explicitly to begin again.

The converged trace is positive only within the entire DECLARED FICTIONAL FIXTURE,
not every real edge, POP, cohort or origin. Partial propagation retains one old
effective route and one old work item. Missing observations leave one unknown
journey and unknown old work. Draining has all sampled routes on v2 but two old
work items. Slow and failed-request traces pass routing/drain but preserve one
interruption. Keeping an old origin does not retroactively erase that failure.

KEYBOARD / ERRORS / RESET
Tab reaches the skip link, trace selector and controls. Arrow keys select a trace;
Enter activates an action. Focus advances to the next useful action. Completed
checks return focus to the selector (or reset at the limit). Unsupported or
out-of-order input raises a visible focused error without changing run state.
Reset clears state/history/errors, restores the default trace and focuses it.
No control is named reset; the native form.reset method is not shadowed.
