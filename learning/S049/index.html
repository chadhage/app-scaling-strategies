S049: Ambiguous POST completion

Commit one synthetic order, lose its response, then choose a controlled retry. A lost reply is not a rollback. A retry is not automatically safe.

Objective: distinguish one business effect with the correct client result from duplicate effects, explicit rejection, and an unresolved client.

Source: README S049; parent D-S049; card A-S049; frozen S; packet SC-S049. Instructions and evidence.
