S024 — Production-configuration validation

Validate effective target settings, including the candidate's retained identity and network, without running a second background worker. This bounded fixture has one active production worker and a working staging dependency.

A-S024 · S · SC-S024 · D-S024 · SOURCE. Resource-free browser lesson only; no Azure, management, authentication, deployment or background-job calls. Native B-S024, original parent acceptance, production Node.js 24 and reliability claims remain unverified.

Conduct the rehearsal

  1. Validate the defaults: staging works, but effective-production readiness is unknown.
  2. Select effective production settings. Retain the staging-only setting, denied grant or blocked route to observe independent failures.
  3. Archive/reset. Select effective production settings, target dependency, granted access and reachable network, keeping candidate work suppressed. All four checks should pass.
  4. Try enabling candidate work: validation must be blocked before any candidate work starts. Try an unobserved target check: the result must be unknown.

Repairs never erase earlier failures or unknowns. The current run's verdict is cumulative; archive/reset starts a fresh unknown run and retains the complete prior trace. All data is in page memory; reloading clears it.
