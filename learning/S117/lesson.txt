Preconditions and measured evidence
Cedar and Maple are invented regions. The network/access/state fields are fixed
fixture-open, fixture-authorized and fixture-synchronized-v7; the identity label
is fictional-shopper. These are teaching labels, never verified Azure access.
Counts and times are calculated deterministically from authored samples:
checkout Cedar 42 ms, Maple 49 ms, failure 70 ms; catalog Cedar 18 ms, Maple 21 ms.
Unknown evidence has null latency. These are not clock or network measurements.
Select only the four fixed fixtures, two journeys and two policies. Sample
counts must be one digit 1–6. History retains at most eight runs. The model
replays and validates every prior trace, count and phase; malformed inputs,
getters, forged state and illegal recovery are rejected without mutation.

Keyboard / reset / errors / startup / CSP
Use Skip to exercise, then Tab through the labelled native controls. Enter in
the sample input submits. Alerts name errors, mark and focus the offending
control, and preserve the result/history. Reset lesson is a separate button;
Space or Enter clears controls, error, tables, summary and in-memory history.
No control uses reset as its id or name. Reload also clears history.
Missing local scripts leave explicit uninitialized/unavailable guidance and
disabled action buttons; they cannot silently report a successful measurement.
CSP permits only external local scripts/styles and denies connections, inline
script, frames, forms, workers, objects and base rewriting. Tests challenge CSP
with an inert inline canary and a local data: fetch; neither contacts a network.
