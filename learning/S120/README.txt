FIXTURE / PRECONDITIONS / ACTIONS
S120-fixed-v1 has two fictional application paths, origin-a and origin-b, in
fictional-region-a and fictional-region-b. Both have fixed capacity 2, state
revision 7 and writer epoch 3 under one shared authoritative state contract.
Demand is 2; at least one reachable compatible path is required. There is no
invented Azure region, SKU or multi-writer capability. 100 ms is a fixed teaching
budget, not an Azure threshold or an actual measured browser duration.

1. Observe the supported control: two acknowledged fixed requests.
2. Confirm removal of origin-a; observe origin-b: two more positive controls.
3. Confirm removal of origin-b as well; observe the total-loss fixture.
   The new read and write return synthetic 503 at 250 ms (two interruptions).
   A third write started before loss has no acknowledgment or completion
   telemetry. Its business outcome and duration are unknown, not success.
   No new write is admitted without authoritative state.
4. Check "Unavoidable interruption": educational verification PASS, user impact
   INTERRUPTED, envelope UNSUPPORTED, 3 affected attempts, 0 successful migrations.
   The positive controls are not migrated users.
5. Check the incorrect zero-downtime claim: the verifier FAILS while those same
   interrupted and unknown outcomes remain. Blind retry is explicitly rejected:
   absence of acknowledgment cannot authorize a new mutation or duplicate effect.
6. Apply the fixed authoritative snapshot and recover one owned fictional path.
   Its pending effect is reconciled once. The original receipt remains unknown.
   Two fresh recovered controls can succeed, but the past interruption is not
   repaired. Cleanup says which one path was restored and that the other remains
   unavailable; it never claims complete recovery of actual resources.
7. Reset: native form.reset remains callable, controls return to defaults, and
   the whole prior run stays in expandable history. Five archives and twelve
   accepted actions per run are enforced; history is never silently truncated.
   History lasts for this page session; a deliberate reload starts a new session.

STRICT GUARDS / ACCESSIBILITY / FAILURE
The model accepts only exact, plain data commands and issued deeply immutable
states. Unknown fields, symbols, accessors, foreign IDs, non-boolean
confirmations, duplicate observations, stale lifecycle actions and exceeded
bounds are rejected without mutation. There is no arbitrary imported state,
capacity, region, request or outcome input. Errors use textContent with an alert
and focused correction control. Native labels, buttons, forms, visible focus,
skip navigation and expandable keyboard history are available.
If scripts cannot load, controls stay disabled and the result stays unverified.
CSP permits local scripts/styles and denies inline scripts, evaluation,
connections, forms, objects, frames, workers and base changes. This is not a
replacement for a qualified C041 host or a generic network sandbox.
The CSP check deliberately loads the owned scripts\csp-probe.js as an external
script: DevTools-evaluated code may bypass evaluation restrictions. Connections
are tested with data: and form submission targets only the owned current file;
no external network call or arbitrary navigation is attempted.

RAW BYTES ARE NOT CANONICAL GIT BYTES
Raw .source/.stub/.raw/.json/.raw.gz proof has narrowly scoped -text attributes
set before capture. Gzip archives preserve exact source bytes, including CRLF.
Narrow whitespace=cr-at-eol rules recognize literal CRLF in raw text proof
without turning off normal source whitespace checks or changing proof bytes.
Literal terminal .raw captures and gzip archives are -diff data; the Node
assertion formatter's indented blank lines are preserved and verified by hash,
not treated as editable source whitespace.
Normal source files have text/eol=lf Git attributes. Historical raw proof is
never edited to match a later canonical Git blob. After scoped publication:
  node learning\S120\scripts\published.cjs <exact-40-character-implementation-sha>
This independently compares the canonical owned Git blobs with git hash-object
--path and checks frozen proof bytes without writing anything or skipping gates.
The reported SHA comes from the scoped publisher receipt, not the moving HEAD.
evidence\worker-result.local.json is an ignored, owned state-report handoff, not
a source proof or an extra commit/credit.
