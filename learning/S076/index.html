S076 — Consumer scale-in

A-S076 · D-S076 · frozen S · one unit A-S076 · packet SC-S076

Remove a consumer holding work; select valid finish, renew, or release behavior. The source requires finishing, renewing, or safely relinquishing claimed work before shutdown.

The declared synthetic contract

Two consumers, one four-unit job, and an exclusive claim owned by consumer-A at tick 0. Consumer-B can resume only after an acknowledged current checkpoint and observed release. One valid owner processes one unit per operator-controlled tick; the job has one intended effect.

A lease is valid only while tick < leaseUntil. Expiry is checked before work at the new tick. Closing admission starts shutdown grace, not a new job deadline. A renewal changes only lease expiry. No automatic timer, broker, background consumer, network operation or platform action runs.

  1. Finish: use defaults. Start, close admission, advance four ticks, retire A, verify.
  2. Renew: select Renew and lease 2. Start, close, tick then renew at ticks 1, 2 and 3. Tick to 4, retire, verify. Try retiring while A still holds unfinished work: it is blocked.
  3. Release: select Release with lease 5. Start, close, tick once, save checkpoint, release, retire A, claim on B, advance three ticks, verify. Removal alone is not job completion; B keeps the original deadline.
  4. Negative and unknown: miss renewal, use work budget 3 or grace 3, or confirm the abrupt-stop fault. Select missing observations to see UNKNOWN instead of fabricated receipts, authority or completion.
