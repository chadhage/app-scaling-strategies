Operator controls

Force-stop interrupts the old HTTP request at 6000 ms or the active durable successor at 8000 ms; no subsequent recovery is presumed. Delayed retry restarts HTTP at 8000 ms (finishes at 20000 ms) or resumes a durable checkpoint at 14000 ms (finishes at 22000 ms). Missing proof removes result identity/units, not the observed envelope timestamp.

Drain is unused after a proved durable handoff. HTTP acceptance must still fit the declared host limit. Exact-deadline completion is allowed; limits never extend themselves.
