WORKED EXERCISE
1. Choose reviewed manual swap or controlled deployment/swap pipeline.
   The Linux native-auto-swap option is disabled, with its reason displayed.
2. Keep the prepared fixture and 250 ms original budget. Assess candidate:
   HTTP 200, meaningful dependency/state checks, target settings and shared
   overlap headroom must pass. Production is the swap target.
3. Promote explicitly. Desired routing changes, but no migration success is
   claimed before measurement. This records no real deployment or swap.
4. Measure three fixed crossing receipts: 3 successes / 3 attempts. The old
   long-running request has a fictional durable continuation receipt.
5. Reset; history remains. Choose former-worker loss, assess, promote and
   measure: 2 successes, 1 interruption / 3 attempts. Request fictional rollback:
   old routing is desired but recovery is not observed; the failure remains.
6. Reset and choose missing observations: 1 success, 2 unknowns / 3 attempts.
   These are unverified outcomes, not success or a reduced denominator.
7. Warm-up 503, wrong target settings and overlap deficit abort before exposure.
   Measuring shows 3 successful old-only production requests and ZERO attempted
   migrations, not a 100% transition. Six archived runs bound this page.

The original budget accepts only unpadded decimal integers from 100 to 500 ms.
It changes acceptance, not the fixed receipts. At 150 ms two healthy HTTP 200
receipts exceed the original budget and count as interruptions. Blank, spaces,
leading zeroes, signs, decimal/exponent notation and out-of-range values fail.

Use Tab, arrow keys, Enter and Space. Errors have a focused live alert and leave
state/history unchanged. Reset clears errors, restores default controls and
focuses the path selector. The button is not named/id'd "reset", so the native
form.reset method is not shadowed. Reset archives exposed unfinished work as
cancelled with 3 unknown transitions; it never deletes prior failures. History
is in memory: reloading starts another lesson, not a durable hosted run.
