Small pools multiply when instances scale out

One frontend and one API instance form the baseline. Add instances, sum every per-instance pool, and inspect shared connection pressure and journey latency.

1. Declare the synthetic operating envelope

Every modeled pool simultaneously requests its configured maximum. This is a deliberately saturated, deterministic teaching workload, not measured database usage. The limit below is your declared synthetic approval, not a platform quota.

Try defaults, then target 4 frontend / 5 API instances to exceed 120 connections. In another attempt keep those counts but reduce the pools to 5 / 10. Compare the retained failure with the recovery.

Configure before observing the baseline; settings then lock

At least one tier must increase beyond its one-instance baseline. Use whole decimal integers, without spaces, signs or exponent notation.

2. Inspect the two-checkpoint synthetic trace

Requested connections = frontend instances × frontend pool + API instances × API pool. Accepted = min(requested, limit); refused = max(0, requested − limit). Synthetic latency, ms = 80 + 2 × ceil(100 × requested / limit) + 200 if any connection is refused.

Both observations must succeed. Exhaustion or over-budget latency fails. Missing or pending observations stay unknown unless another known failure already exists. Configured ceilings are forecasts, never observed database evidence.

    What this rehearsal does not prove

    No real connection is opened, pool filled, instance scaled or database exhausted. Idle/minimum pools, traffic distribution, other applications, retries, pool wait queues and real database behavior are not modeled. A configured maximum is not a measurement of current connections. All invented latency values are lesson rules.

    No authentication, credentials, registration, Azure management, infrastructure, deployment or spending. This does not certify native behavior, production Node.js 24, B-S062, D-S062 or five-nines reliability. Native/source-parent acceptance remains incomplete.
