## Public replay watchdog is not worker admission

Ordinary replay uses a per-command local failure watchdog (30 minutes by
default), optionally `C012_LOCAL_VERIFY_MS` or `C012_LOCAL_VERIFY_DEADLINE`.
It does not expire merely because the original worker GO has ended and grants
no worker/cloud/expenditure authority. `C012_PRIVATE_WORKER=1` additionally
clamps this worker's commands to the exact original deadline; the private outer
watchdog remains unchanged. The old fixed-budget source is retained under an
explicit historical role. A simulated-after-worker-deadline control verifies
both separation and the worker hardstop.

Public local commands, from the checkout root, are:

```powershell
node capability\C012\tests\public-v3-suite.cjs
node capability\C012\tests\coverage.cjs
node --expose-gc capability\C012\tests\mutations.cjs
node capability\C012\tests\current-v2-close.cjs
node capability\C012\tests\public-v3-final.cjs verify
```

Set fresh owned output directories using the documented `C012_*_OUTPUT`
variables before capture commands. Original-private projection derivation
requires the explicit read-only `C012_PREDECESSOR_NAMESPACE`; when it is
unavailable, that derivation is reported unavailable, not passed.
