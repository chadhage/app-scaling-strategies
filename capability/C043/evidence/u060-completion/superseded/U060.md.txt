## Retained failure and actual root

The old480s complete gate printed only its successful control test. Its runner
waited for child stream closure, killed only the direct child on a timer, and
could count a null exit as a kill if partial output named an assertion.
The failed-step mutation also removed the only stop on an unsuccessful step:
with a static injected clock its loop revisits an unacknowledged step instead
of returning to the waiting assertion. A wall-clock timeout cannot prove a kill.

The new deterministic RED executes the actual retained runner callback with
a controlled named failure and virtual expiry. The old callback accepts it;
the unchanged oracle rejects that bookkeeping and passes on the repair.
Old timeouts remain immutable failed observations, not this RED.

## Repair

The complete original79 names and text replacements are preserved. Children
use explicit Node test mode, no inherited test/coverage context, and an
identity-recorded startup gate. The initial authored `--import` gate did not
run in Node's test coordinator; its separate actual-startup RED and failed
campaign remain retained. The corrected synchronous require gate holds both
the coordinator and its test workers until their live identities are recorded.
Cleanup uses the frozen identity-based lifecycle
core, never image names or bare ambient parent links. Child exit, spawn failure,
incomplete streams and timeout are explicit outcomes; none can be a kill.

The test-only in-memory loop observation counts at most the declared steps plus
one terminal visit. Unmutated maximum-eight-step controls pass on a static
clock; a repeated failed-step mutation reaches a named iteration assertion
instead of starving its waiting test. No production file changes.

Unexpected rejection of an operation that an existing test expects to resolve
is asserted explicitly without changing the original test names. Filesystem
name, parser-header and first-request timer predicates are exercised directly:
invalid OS paths and missing socket callbacks cannot hide behind long waits.
Each application emits a marker. A kill requires complete TAP, zero cancelled
or todo tests, no infrastructure error, a named assertion and confirmed cleanup.
Each active/completed mutation is reported. The shared mutation holder uses
at most two subprocess workers; a generous process liveness limit is not an
approval deadline or success criterion.

All previous D1-D4/head, U058/U059 evidence and13 production bytes stay exact.
Exact current tooling is superseded only through append-only authority.
A consistent rewrite of verifier, heads and data still requires independent
history review; namespace hashes alone do not authenticate that rewrite.
