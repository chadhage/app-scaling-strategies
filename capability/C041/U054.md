# U054: explicit raw and canonical lesson-asset pins

This is a private C041 amendment proposal, not acceptance, application or
publication authority. It changes only `serve.cjs`, `accepted-catalog.js` and
three exactly named C041 tests. Original manifests, snapshots, raw archives,
lesson assets, imported producer files and all consumer files remain unchanged.

The eight asset records retain `sha256` and add `rawSha256` and
`crlfToLfSha256`. The raw check short-circuits the canonical check. The canonical
operation removes CR only immediately before LF, using a byte-preserving
Latin-1 round trip. It does not decode/re-encode UTF-8, remove a BOM, replace a
bare CR or transform the returned Buffer. Existing raw-only `verifyAsset`
callers and the old catalog schema remain supported. Integrity refusals now
name the asset path.
