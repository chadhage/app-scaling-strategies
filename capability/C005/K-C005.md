# K-C005: hermetic publisher binding (quality debt, zero credit)

K-C005 serves C005 [S] and publishes under the original card ID and class. It repays one debt: two accepted C005 checks hashed the
live private publisher (`.git\kanban-orchestrator\publish.ps1`) and so failed as soon as the publisher was replaced by a later
approved version (lesson L-0017). It adds fixtures, tests and evidence only. No production source, sealed evidence or retained RED
changed; the only edits to existing files replace the stale pin of the live publisher's bytes in two test files.
