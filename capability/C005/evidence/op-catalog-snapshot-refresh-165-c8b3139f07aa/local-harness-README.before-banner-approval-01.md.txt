## One continuous learner journey

1. Search for **blue-green**.
2. Select **AKS**, **UNCLASSIFIED**, and **Portable accepted (historical snapshot)**.
   The controls combine with **AND**; S001 and S128 match with **unknown**
   native-host support. S124 is separately excluded by its unchanged P001 host
   prerequisite. Choose S001 for the continuous conductible rehearsal.
3. Open **Read S001 preparation**. Read its exact source objective, implementation,
   acceptance, additional prerequisites and inherited BASE. Expand the original
   dependency, operating-limit, Done and evidence excerpts and inspect C001/C003
   boundaries. Missing values are not defaults.
4. Open the **original accepted synthetic lesson A-S001** in a separate tab.
   Read that lesson's own preconditions and limits, then conduct its controls.
   Close the tab to return here. **Back to these results** preserves the query
   and all filters and focuses the entry's preparation button.
5. **Reset local view** clears query, filters and preparation, restores all
   152 entries and focuses search. It is not cloud cleanup or lease release.

**Training rehearsal — synthetic data — not a live Azure result.**

## Failure, keyboard and local safety

Missing/incompatible providers, malformed data, invalid filters or invalid
selection clear results, preparation, links and provenance immediately. Errors
are alerts, distinct from successful no-match searches. Reset cannot resurrect
an older valid catalog after an invalid replacement mount. Revision guards
reject stale asynchronous preparation; remount/dispose detach old handlers.

Native inputs/selects/buttons support keyboard operation, visible focus, live
counts, preparation-heading focus and return focus. Literal source/query text is
never parsed as HTML. CSS reflows at 320 pixels. This is not a full WCAG or
assistive-technology certification.

The CSP denies connections, inline code, images, frames, objects, workers and
forms. Accepted lesson links open original files, not a copied exercise.
