# U040 fix 2 (addendum 2): the exact commands

Run every command from the repository root in PowerShell 7 with Node 22, never inside a wrapper that sets `$ErrorActionPreference = 'Stop'`. The recorder of the run (`archive-run.cjs`, a shared tool that is not part of the repository) runs one node command from the repository root with `NODE_TEST_CONTEXT` and `NODE_V8_COVERAGE` removed and writes the manifest and the gzip transcripts of this folder; every manifest records the SHA-256 of its inputs. Paths in the manifests are repository-relative; the raw transcripts of the two REDs contain the absolute path of the checkout (the recorder runs from the repository root and Node prints the location of a failing test), which is a limit of the recorder, not of the tests.

Machine rules that applied: normal priority, at most 4 CPU-hungry workers on the machine, the real Edge run in a heavy slot, the loop in the single loop slot, the mutation run in a mutation slot with at most 2 workers, and a hard external timeout on every command. No result is decided by a clock: the bounds in the tests only end a wait that would otherwise hang.
